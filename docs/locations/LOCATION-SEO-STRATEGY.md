# EntireFM Location Authority & Geographic SEO Strategy

## 1. Executive Summary & Core Rules
EntireFM's geographic estate is built on genuine historic URL authority, verified regional mobile engineering coverage, and high-value buyer decision tools.

### Core Historic URL Protection
- **Zero URL Consolidations**: Parallel historic city variants (e.g. `/fm-london`, `/facilities-management-london`, `/london-facilities-management`) are preserved as independent HTTP 200 URLs.
- **Strict Query Ownership**: Each parallel variant serves a distinct search intent and buyer need rather than duplicating generic copy.
- **Zero Doorway Spam**: No mass-generated programmatic `SERVICE × CITY` or `SECTOR × CITY` permutations.
- **Zero Fake Premises**: Operational coverage is accurately described as national mobile engineering coordinated centrally and deployed regionally; no fabricated regional offices or fake Google NAP listings.

```
  GEO SEARCH INTENT ──► LOCAL ESTATE CONTEXT ──► SECTOR/SERVICE FIT ──► TENDER GUIDANCE ──► CONVERSATION
```
