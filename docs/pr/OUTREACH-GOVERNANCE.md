# EntireFM Digital PR Outreach Governance & Standards

## 1. Non-Negotiable Human-in-the-Loop Rules
- **Zero Mass Automated Blasts**: Every media pitch is drafted based on verifiable relevance and must be manually approved and sent by a human editor.
- **Strict 1 Follow-Up Limit**: A single polite follow-up is permitted 4–5 business days after the initial pitch. If no response is received, the target is marked `UNRESPONSIVE` and no further contact is made.
- **No Paid-Link Schemes or Directory Spam**: EntireFM never purchases backlinks, uses PBNs, or engages in manipulative anchor text schemes.
- **Strict Opt-Out & Preference Respect**: Any request to be excluded immediately marks the contact and publication as `DO_NOT_CONTACT` globally.
