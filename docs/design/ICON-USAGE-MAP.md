## 2. Utility Icon Rules (What Stays Lucide)

The following basic browser and interaction controls intentionally remain simple Lucide SVG components:
* `Menu` / `X` (Mobile Drawer trigger)
* `ChevronDown` / `ChevronRight` / `ArrowRight` (Navigation & link indicators)
* `Phone` (Small text inline phone indicator)
* `Mail` (Small text inline email indicator)
