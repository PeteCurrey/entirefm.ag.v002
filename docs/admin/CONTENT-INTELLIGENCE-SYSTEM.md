# EntireFM Content Intelligence & Growth Engine

## 1. System Architecture
The Content Intelligence Engine provides closed-loop analytics and search performance feedback into the EntireFM editorial system.

```
Search Demand + Regulatory Watch + Existing Page Performance + Competitor Gaps
                                   ↓
                       Editorial Decision Engine
                                   ↓
                     Create New or Update Existing
                                   ↓
                         Publication Gate
                                   ↓
                         Live Verification
                                   ↓
                         Performance Audit
```

## 2. Existing URL First Policy
If an existing URL has historical ranking or authority for an intent, EntireFM updates and expands the existing page rather than creating duplicate content.
- Example: Update `/ppm` rather than creating a new redundant guide `/ppm-guide-2026`.
- Historic Wix URLs are permanently protected against automated redirection, deletion, or de-indexing.

## 3. Weekly Intelligence Briefing
Generated weekly on Mondays, combining:
- 1 Search-Demand Opportunity
- 1 Current FM Regulatory / Technical Development
- 1 Evergreen FM Guide
- 1 Technology / CAFM / Commercial Topic
- Optional 5th Specialist Sector / Compliance analysis
