# EntireFM Planned Preventative Maintenance (PPM) Mobilisation

## 1. Maintenance Regime Formulation
The PPM matrix is generated using:
- Statutory and regulatory standards (SFG20, CIBSE, F-Gas).
- Manufacturer specifications.
- Contractually agreed client frequencies.

## 2. Technical Approval Gate
- PPM plans require formal technical review and client approval before becoming active scheduled work orders.
